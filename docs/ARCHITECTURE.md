# 从模型候选到阅读区域

## 实现边界

`app/android/app/src/main/java/com/gejian/gejian/ComicEngine.java` 保存原生页面算法；`MainActivity.kt` 负责 Android 接口；`app/lib/reader.dart` 组织传统漫画阅读；`vertical_reader.dart` 负责独立条漫滚动分支。发布整理没有改动页面处理算法或替换模型。

## 处理流水线

1. **本地推理**：MAGI 提供画格、文本、人物等候选，YOLO 实例分割提供气泡/画格轮廓。缩放分析后恢复到原图坐标，保留原图用于显示。
2. **背景与分镜证据**：结合候选、背景色、暗区域和灰底框线；OpenCV 边缘及线段证据用于区分斜沟槽、真实黑框和画内结构。可靠性不足时保守回退。
3. **框外内容归属**：模型文本/对白与框线证据恢复未被普通检测框包住的区域。不是把每个框任意扩大，而是在邻格约束下扩展所属区域；避免外扩吞进尚未揭晓的画面。
4. **关联分镜**：共享气泡轮廓或高置信人物/连续身体证据可建立 artworkGroup，将相关区域同一步显示。既保留跨格关联，也保留独立画格的分步性。
5. **完整区域覆盖**：递归分析横纵沟槽分配页面区域；斜向边界使用多边形距离等几何约束。输出原图坐标的复合路径，处理孔洞，单独保存非白纸面的 stockPaths，并约束未来画格黑框。
6. **阅读步骤**：先确定行层次，再从右向左排序；非白纸面可以成为最先显示的背景步骤，关联区域按组加入。无可靠分格证据以及大跨页使用整页分支。
7. **累积渲染**：将已揭晓的归属路径取并集，裁切原图。completeRegions 页面即使到最后一步，也使用归属路径并集，不靠突然取消裁切补出遗漏事物。边框、文字和颜色来自原图。

这里的“跨格气泡”指同一页多个画格之间的关联；“跨页识别”包含横向大跨页的整页回退。没有声称重建跨物理页面的三维场景或训练新的跨页语义模型。

## 预加载与条漫

下载、解码和识别结果在后台预取，合并重复请求，并使用有界结果缓存（最多 8 个识别结果）限制常驻资源。预加载调度复用原算法，不以降低模型精度或跳过页面规则换速度。磁盘/网络/设备仍影响首次等待时间，未提供未经测量的加速倍数。

条漫使用屏宽缩放和连续滚动，绕过传统逐格流程；气泡点击放大保留。普通页与条漫的逻辑分支独立。

## 模型归属与局限

MAGI、YOLO 权重均为上游现成模型。页面归属、关联、排序和阅读器集成是本项目处理层。识别可能误判复杂构图，样本回归不构成通用准确率保证。请结合 [案例](GALLERY.md)、[本次验证](../release/VERIFICATION.md) 与源码检查具体行为。
